# Evaluation evidence

This directory contains dissertation-facing evidence and analysis. It is not
used by the runtime package.

The protected-holdout results bank is the primary source for the final unseen
25-example comparison. The three-condition dossier and post-development bank
contain supporting prompt-condition, model-strength, ablation, and exploratory
results. Focused notes are retained in `notes/` to keep claims traceable to the
experiments that motivated them.
